# Backlog

What is next on aura-android, roughly in order. This tracks the phased roadmap in the porting plan (`aura-apps/specs/android-port.md`, section 11).

## Done

- 2026-08-25: Added the WorkManager background refresh so the widget stays current while the app is closed. `work/RefreshWorker.kt` is a `CoroutineWorker` that reads the saved favourites and calls `WeatherRepository.refresh(...)` (which skips anything cached within the hour, obeys AEMET's rate limit, and nudges the widget itself); it succeeds quietly when there are no favourites or no AEMET key, and returns `Result.retry()` on a transient failure so the last good cache stays on the tile. `work/WeatherRefreshScheduler.kt` enqueues it as *unique* periodic work (`ExistingPeriodicWorkPolicy.KEEP`) on every `MainActivity.onCreate`, so relaunching never resets or stacks the schedule; cadence is 3 hours (matching the iOS widget reload) under `NetworkType.CONNECTED` + `requiresBatteryNotLow`, keeping to the idle-by-default battery discipline. WorkManager self-initialises via androidx.startup, so no Application subclass or custom Configuration was needed. WorkManager 2.10.1 pinned in the catalog. Verified on the emulator: the job schedules with the exact constraints (`dumpsys jobscheduler` shows `TIME=+2h59m…`, `NET BATNOTLOW`) and a worker ran and called `jobFinished` cleanly. Full suite green, debug APK builds clean.

## Standing notes

- The AEMET key is shared and never committed (plan section 9). It is stored per-device via `SecretStore` (Keystore-backed `EncryptedSharedPreferences`), entered by the user, never in the binary or repo.
- `androidx.security:security-crypto` is deprecated by Google; we deliberately stay on 1.1.0-alpha06 (its terminal release, so "alpha" means "last", not "churning") because it is the documented, single-secret path and swapping in a plain Keystore-AES wrapper later touches only `SecretStore.kt`.
- The 24h/12h clock lives as a mutable flag on `:core`'s `AuraTime` (matching the Swift static), kept in step with the `Settings` DataStore boolean by `HoyViewModel` — the one place `:app` writes it. Compose reads it synchronously; `:core` stays android-free.
- Device location resolves to a `:core` `Coordinate`, which `SpainCities.nearest` turns into the closest bundled municipality (its INE then drives the forecast). `LocationProvider.current()` bounds the live-fix wait at 8 s (`withTimeoutOrNull`) before falling back to last-known and then `NoFix`, so a cold start can't hang the first paint. The three no-fix outcomes (permission denied, services off, no fix) are distinct all the way to the UI: "Hoy" shows a fallback banner, and Ubicaciones' "Usar mi ubicación" shows a matching notice.
- Location uses the platform AOSP `LocationManager` (via `LocationManagerCompat.getCurrentLocation`), never Google Play Services. This keeps Aura working on GMS-less devices and behaving the same on every OEM as on the emulator. `:app` acquires location and hands `:core` a plain `Coordinate`; `:core` stays free of any `android.*` or `com.google.*` import. Full spec in the local `specs/location.md`.
- Test-device plan: a Pixel is the clean development reference; the real OEM variety (Samsung, Xiaomi) comes from Samsung Remote Test Lab and Firebase Test Lab rather than more hardware. Watch for OEM background-killing (WorkManager for any refresh, never a bare service).
- The Home Screen widget (Jetpack Glance) never calls AEMET: it re-renders whatever the app last cached, reading the same `SnapshotCache` + `Settings` the app writes (no App Group needed on Android; the widget shares the app process). The app is the fetch hub and nudges `AuraGlanceWidget().updateAll()` after each refresh. Because Glance renders to RemoteViews rather than Compose, the widget cannot reuse `AuraSky`/`ConditionGlyph`; it bakes `Palette.skyGradientColors` into a bitmap and draws a restricted text layout. Full spec in the local `specs/widget.md`.
- The version stack is pinned deliberately. Read `CLAUDE.md` before bumping anything.
- MITECO's air-quality host has an incomplete TLS chain. The fix is a scoped Network Security Config trust-anchor for that domain only, not a global bypass (plan sections 5 and 10).
